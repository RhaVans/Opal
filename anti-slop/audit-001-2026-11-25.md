## Numbered Findings & Resolutions

1. **HIGH (R-26 / Functional Correctness)** `StudyStudio.tsx`, `tts.ts`, `TTSButton.tsx`, `GlossaryDialog.tsx`: TTS spoke `currentCard.ttsText` (a rephrased answer string on 152/211 cards) even on the unflipped question side, and did not reset state on card change or support Android WebView native TTS. **Fixed:** Question TTS speaks `prompt.jaPlain`, Reveal Answer adds dedicated Answer TTS speaking `answer.jaPlain`, `TTSButton` synchronizes active utterance and stops on card change, and `tts.ts` bridges `window.AndroidTTS` for APK builds.
2. **LOW (R-20 / Brand Voice)** `src/lib/chapters.ts`: Indonesian greeting displayed `"ulas kartu jatuh tempo"` instead of the concierge greeting. **Fixed:** Updated greeting subtitle to `"Concierge"` across time-of-day branches.
3. **HIGH (R-26 / R-03 Functional Input)** `MathSprintDrill.tsx`, `mathGenerator.ts`: Numeric keypad lacked a `,` key while yen answers display `¥15,000` and Indonesian users enter decimal commas like `62,5`, and `replace(/,/g, '')` conflated `62,5` with `625`. **Fixed:** Added `,` key in 3x4 keypad + 4-column Clear/Backspace/Check Answer row, and added `parseNumericAnswerInput()` distinguishing decimal commas from thousands separators.
4. **MEDIUM (R-19 / R-37 Owner Motion Direction)** `BottomDock.tsx` -> `FluidDockOrb.tsx`: Center orb was a static `#4D3EA3` circle with minimal `active:scale-95` feedback. **Fixed:** Replaced with Canvas 2D domain-wave liquid animation in the exact `#4D3EA3`/`#758AD1`/`#E1DAFB` palette, spring press squish, radial ripple rings, and `220ms` route-launch transition respecting `prefers-reduced-motion`.
5. **HIGH (R-25 WCAG Contrast)** `OjigiKeigoDrill.tsx`: Wrong-choice `#CC2F52` button subtitle used white text at `opacity-85` (~3.8:1 < 4.5:1 AA). **Fixed:** Replaced with full-opacity white on `#CC2F52` and `#5B5B62` on light.
6. **HIGH (R-39 Semantic HTML & Landmarks)** `StudyStudio.tsx`, `GlossaryDialog.tsx`, `stats/page.tsx`: Nested `<main>` inside `RootLayout`'s `<main>`, plus duplicate `<h1>` headings inside modal dialogs. **Fixed:** Switched nested `<main>` to `<div>` and dialog titles to `<h2>`.
7. **HIGH (R-26 / R-39 Dead Control & Disabled State)** `ArrowButton.tsx`, `cbt/page.tsx`: Start `ArrowButton` stayed enabled when Weak scope had 0 items, silently ignoring clicks. **Fixed:** Added `disabled` prop and visual disabled state to `ArrowButton`.
8. **HIGH (R-26 State / Routing Bugs)** `StudyStudio.tsx`, `ExamRunner.tsx`, `ExamSummary.tsx`, `SequenceDrill.tsx`, `TableLayoutDrill.tsx`, `StatsPage`:
   - Opening `/study?chapter=1` from Chapters "All" filter defaulted to `'due'` (showing empty queue if all reviewed) and failed to reset session when switching chapters client-side -> fixed default mode and session reset.
   - Rapid double-taps on rating buttons could write duplicate SRS updates -> added `ratingPendingRef` lock.
   - `ExamRunner` timer interval tore down and restarted on every option click and called `submitSession()` inside a state updater -> moved latest answers to `selectedMapRef` and auto-submitted cleanly via effect.
   - `ExamSummary`, `StatsPage`, `TableLayoutDrill`, `OjigiKeigoDrill`, `MathSprintDrill` ignored Indonesian text under `jp_id_en` or hardcoded `.en` -> aligned with `settings.langPreset`.
   - `SequenceDrill` and `TableLayoutDrill` failed to reset `startedAtRef` on replay.
9. **HIGH (R-03 Mobile Safe-Area & Grid Containment)** `layout.tsx`, `drills/page.tsx`: `<main>` lacked dynamic `env(safe-area-inset-bottom)` clearance above `BottomDock` + orb, and `grid-cols-2` cards on `/drills` lacked `min-w-0`. **Fixed.**
